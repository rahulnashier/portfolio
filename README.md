# Portfolio

My personal portfolio site, built from scratch with plain HTML, CSS and JavaScript while I learn web development.
🔗 **Live site:** https://rahulnashier.github.io/portfolio/


## Features

- Responsive layout with a mobile nav menu
- Smooth scrolling with the current section highlighted in the nav
- Accessible focus styles and a skip-to-content link
- robots.txt and sitemap.xml for basic SEO

## Tech used

- HTML5
- CSS3
- Vanilla JavaScript
